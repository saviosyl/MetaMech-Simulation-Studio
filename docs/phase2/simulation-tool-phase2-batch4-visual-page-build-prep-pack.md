## 5) Design Direction Notes (for visual/page build consistency)

## Visual tone
- Premium industrial SaaS
- Calm, technical, and credible
- Confident without being aggressive

## Layout feel
- Structured and breathable
- Clear section hierarchy
- Strong scan path from value -> proof -> pricing -> action

## Spacing feel
- Generous whitespace around major blocks
- Tight but readable spacing in feature/pricing cards
- Avoid dense walls of text

## Premium vs technical balance
- Premium surface quality (clean cards, subtle shadows, restrained accents)
- Technical proof visible (connections, flow behavior, reliability cues)
- Keep visuals practical, not ornamental

## What to avoid
- Overly dark/heavy visual treatment
- Overloaded UI collages in hero
- Generic stock visuals
- Excessive jargon or hype-style labels in graphics
- Cluttered pricing section with too many options
